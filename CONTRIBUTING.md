# Contributing

Thanks for considering a contribution. This project is an offline educational simulator for studying baccarat probability, bankroll behavior, and Martingale-style betting risk with pretend money.

## Project Scope

Good contributions should support education, simulation clarity, source-code quality, or release readiness. The project should remain local-first and should not connect to casinos, betting services, or real-money systems.

## Responsible-Use Rules

- Keep the project framed as an educational simulation.
- Use pretend-money language for bankrolls, units, stakes, and results.
- Do not describe any strategy as a way to beat baccarat.
- Do not present simulation output as gambling or financial advice.
- Avoid claims that a betting system is safe, guaranteed, or profitable in real play.

## Running Checks

Install dependencies:

```bash
npm install
```

Run tests:

```bash
npm test
```

Build the app:

```bash
npm run build
```

## Suggested Contribution Areas

- Documentation and release notes.
- UI clarity and accessibility.
- Simulation explanations and result interpretation.
- Tests for rules, strategy behavior, and summaries.
- Export tools such as CSV downloads.
- Charts and result summaries that make risk easier to inspect.

## Prohibited Contribution Directions

- Casino automation.
- Real-money betting integrations.
- Claims that systems beat baccarat.
- Tools designed for live gambling assistance.
- Scrapers, bots, credential handling, or platform-specific gambling workflows.
