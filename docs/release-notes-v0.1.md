# v0.1 Educational Simulator Snapshot

Initial public educational snapshot of Baccarat Strategy Sandbox, an offline simulator for studying Martingale-style betting risk with pretend money.

## Included

- Manual baccarat dealing with configurable shoe settings.
- Strategy Lab simulations for single sessions.
- Batch session analysis for comparing many independent runs.
- Pretend bankroll and unit controls.
- Road-chart visualization for manual or simulated outcomes.
- Responsible-use documentation and public release checklist.

## Responsible-Use Notice

This release is for education, probability visualization, source-code study, and portfolio demonstration only. It is not gambling advice, financial advice, a real-money betting tool, casino automation, or evidence that Martingale or any betting system can beat baccarat.
