# Responsible Use

Baccarat Strategy Sandbox is an educational simulation project. It is designed to help people inspect probability, variance, bankroll limits, and Martingale-style betting risk using pretend money.

## Boundaries

- Educational simulation only.
- Pretend money only.
- No casino connection.
- No betting-service connection.
- No gambling advice.
- No financial advice.
- No automation for gambling platforms.
- No claim that Martingale or any betting system can beat baccarat.
- No claim that simulated results prove real-world profitability.

## Intended Uses

- Probability education.
- Risk visualization.
- Bankroll and tail-risk experimentation.
- Source-code study.
- Portfolio demonstration.

## Interpretation Notes

Simulation output is useful for observing patterns, variance, and failure modes under the rules implemented by this project. It should not be used for real-money decisions or as evidence that a betting system can overcome baccarat's negative expected value.

Martingale-style progressions can make short sessions look stable because they trade frequent small gains for occasional large losses. Finite bankrolls and table limits break the assumption that the next doubled bet will always be available.
