# Roadmap

This roadmap describes practical public-demo improvements. It does not include real-money betting features, casino integrations, or gambling automation.

## v0.1 Educational Simulator Snapshot

- Polished README and responsible-use docs.
- Screenshots and short demo GIF or video.
- Desktop release notes.
- Baseline Strategy Lab presets.

## v0.2 Simulation Usability

- Export simulation results as CSV.
- Clearer result explanations.
- Improved batch-run summaries.
- Optional random seed display and copy action.

## v0.3 Analysis Improvements

- Variance summaries.
- Confidence intervals where appropriate.
- More strategy presets.
- Comparison charts between strategies.

## v0.4 Public Demo / Teaching Mode

- Web demo if feasible.
- Guided tutorial mode.
- Explanatory notes for new users.
- Example scenarios showing bankroll failure and tail risk.
